# IMAGS

To learn about the specifics of our progress, see the final presentation `Final-Presentation.pdf` and report `IMAGS-C26-Report.pdf` <br>

**Abstract:** The Music-Induced Analgesia Genome Study (IMAGS) is an ongoing research project focused on understanding the correlation between music and chronic pain awareness. To measure this correlation, we gather physiological data using a Galvanic Skin Response (GSR) sensor and compare it against musical features like tempo, loudness, and energy gathered using Music Information Retrieval (MIR) software. During our time working on the project, we developed supplemental hardware and software to perform research in parallel with the other teams currently working on IMAGS.
